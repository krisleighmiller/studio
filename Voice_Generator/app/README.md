# Voice Profile Studio

Tauri desktop application for creating and managing one voice profile for one character.

The initial scaffold contains the character target, voice-source selection, a built-in voice catalog placeholder, a designed-voice form, and a microphone recording prototype. Atlas catalog discovery, preview generation, profile persistence, and character-file integration are planned next.

## Development

```bash
npm install
npm run tauri dev
```

The frontend can be checked independently with:

```bash
npm run build
```
