# Studio

A human-directed video production workspace built with Electron, TypeScript and a Rust host. Keep scripts, characters, voices, reference images, shots, takes and revisions together without giving up creative control.

- **[Product and code reference](Desktop_App/docs/studio-reference.md):** what the current source does, why the workflows are arranged that way, implementation limits and source links.
- **[Workflow help](Desktop_App/src/docs/workbench-guide.md):** practical screen-by-screen help, also available through F1 in Studio.
- **[Development and launch](dev-container/README.md):** the maintained Docker workbench, builds and provider/keyring setup.
- **[Desktop application](Desktop_App/README.md):** application overview and quick development entry point.

The product/code reference describes source behavior, not a packaged release or the build loaded in an already-open window. Old Dev Notes have been retired; they are not the current execution plan.
